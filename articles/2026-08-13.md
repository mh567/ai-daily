## 今日简讯

### DeepSeek V4 Pro 正式版 API 上线，增强 Agent 能力

DeepSeek 团队于 8 月 12 日晚在社群宣布，DeepSeek V4 Pro 正式版已更新至 API，调用模型名保持不变。新版本增强了 Agent 能力，支持 Responses API 和 Codex 接入。

据官方公布的基准测试结果，DeepSeek V4 Pro 正式版在终端 Agent 测试 Terminal Bench 中得分为 87.9 分，接近 Fable 5 的 88.0 分。

> 来源：[OSCHINA](https://www.oschina.net/news/501912/deepseek-v4-pro-0813)（2026年8月13日）
