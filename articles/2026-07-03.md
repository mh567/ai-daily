## 🔥 今日头条：GitHub Copilot 首次接入开源模型，Kimi K2.7 Code 正式上线

月之暗面 Kimi 宣布，其开源模型 Kimi K2.7 Code 正式接入 GitHub Copilot，这是该平台首次引入开源模型。

- Kimi K2.7 Code 由 GitHub 托管于微软 Azure 平台，采用按量计费模式
- 逐步向 Copilot Pro、Pro+ 及 Max 订阅方案开放，后续将扩展至 Business 和 Enterprise 版本
- GitHub 官方表示将分批推送，持续监测模型质量与性能

> **编辑点评**：作为开发者工具生态的标杆，GitHub Copilot 向开源模型开放接口，标志着闭源与开源模型在核心开发场景的融合加速，Kimi 借此切入全球开发者市场。｜ ★★★★★

## 📰 今日要闻：OpenAI 拟向美国政府出让 5% 股份以缓解监管压力

OpenAI CEO Sam Altman 向特朗普政府提议，将公司 5% 的股权转让给美国主权财富基金，以缓和与政府的紧张关系，并应对公众对 AI 的反弹情绪。

- 据 Financial Times 报道，双方正处于初步谈判阶段
- 美国副总统哈里斯公开表示对此提议感到"非常不适"
- 该方案被认为是 OpenAI 在面临监管收紧背景下做出的战略妥协

> **编辑点评**：出让股权本质上是一次政商博弈，OpenAI 试图用利益绑定换取政策空间，但政治层面的争议已迅速发酵。｜ ★★★★☆

> 来源：[Bloomberg](https://www.bloomberg.com/news/videos/2026-07-02/harris-uncomfortable-with-us-taking-openai-stake-video)（2026年7月2日 22:50）

## 📰 今日要闻：阿里内部全面禁用 Anthropic Claude 产品，员工被要求卸载

电商巨头阿里巴巴内部宣布反向禁用 Claude，员工须卸载包括 Sonnet、Opus、Fable 及 Claude Code 在内的所有 Anthropic 相关产品，禁令于 7 月 10 日生效。

- 此前阿里对员工使用外部模型实行大额报销政策，鼓励采用 AI 工具
- 消息人士透露，此举与数据安全及内部模型推广策略有关
- 阿里内部模型免费额度仍将维持

> **编辑点评**：在大模型竞速中，头部企业从"开放使用"转向"强隔离"，标志着技术竞争进入地缘与安全考量的新阶段。｜ ★★★★☆
