## 今日头版

### Kimi K3 开放模型权重、技术报告和关键 Infra 技术

月之暗面在 Kimi K3 开放日宣布开放 Kimi K3 的模型权重、技术报告，并开源支撑模型训练的关键 Infra 技术：MoonEP、FlashKDA 和 AgentEnv。官方表示，此举旨在加速前沿智能的部署与普及，促进 AGI 研究，并坚信开放权重模型的价值。

Kimi K3 总参数量达 2.8 万亿，是全球首个开源的 3 万亿级别模型，面向长程编程、知识工作和推理等前沿智能场景设计。

> 来源：[OSCHINA](https://www.oschina.net/news/481061)（2026年7月28日）

### 华为官宣昇腾 0day 支持 Kimi K3 的训练适配及推理部署

### 火山引擎开源 Agent 驱动的搜索自迭代技术

火山引擎开源了 Agent 驱动的搜索自迭代技术。该技术旨在解决 Agent 搜索中“结果不好时能否找到改进方向，并通过实验把搜索变好”的难题。会调用搜索只是第一步，自迭代能力帮助 Agent 持续提升搜索效果。

### 阿里云 Qoder 上线实时语音交互智能体 QoderVoice

阿里云 Qoder 上线实时语音交互智能体 QoderVoice，由全双工语音模型 Qwen-Audio-3.0-Realtime 驱动。用户可随时语音唤醒智能体，通过语音下达指令、讨论方案，智能体实时响应并执行任务。在 Qoder Quest 模式主界面点击语音入口，即可唤起语音助手悬浮窗。用户发起语音指令后，Qoder 自动创建任务、调用工具并在后台执行，用户无需停留等待结果，对话过程中可随时打断、追问或调整需求。
