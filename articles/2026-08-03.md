## 今日简讯

### 阿里巴巴发布 Qwen3.8-Max，宣称基准测试成绩比肩 Anthropic

阿里巴巴集团发布了其迄今规模最大的 AI 模型 Qwen3.8-Max，并宣称该模型在性能上与全球领先的 Anthropic PBC 相当。这是中国 AI 领域挑战美国竞争对手的最新突破。

> 来源：[Bloomberg](https://www.bloomberg.com/news/articles/2026-08-03/alibaba-drops-another-china-ai-model-with-breakthrough-performance)（2026年8月3日 05:20）

### DeepSeek 发布首次 API 调用指南，支持主流开发工具直连

DeepSeek 官方 API 文档发布了“首次 API 调用”指南。根据文档，使用 Claude Code、GitHub Copilot 或 OpenCode 等工具的用户，可以直接将 DeepSeek 作为后端模型使用，无需编写代码。

> 来源：[api-docs.deepseek.com](https://api-docs.deepseek.com/)（2026年8月2日 18:15）
